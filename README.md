# Soccer
Jeu Unity 3D où avec une balle, on doit pousser des ballons dans le but adverse. Plus les niveaux avancent, plus les balles vont vite et plus elles sont nombreuses. Des boosts sont la pour aider à avoir plus de force. Le joueur peut aussi appuyer sur Espace pour avoir un Boost.

Ce jeu a été créé en suivant le site officiel : https://learn.unity.com/pathway/junior-programmer/unit/gameplay-mechanics/tutorial/challenge-4-soccer-scripting-1?version=6.0

Vous pouvez le tester en suivant ce lien : https://play.unity.com/en/games/c3c4f69c-480b-4cca-8a77-6c2b470bafec/exportwebsoccer
